# ТЗНК тренажер

Статичний тренажер для підготовки до тесту загальної навчальної компетентності (ТЗНК), обов'язкового блоку ЄВІ для вступу до магістратури.

## Що вміє

- **Симуляція іспиту.** Повний тренувальний варіант: 33 пункти, таймер 75 хвилин, порядок відповідей як в оригіналі. Результат у тестових балах і орієнтовно за шкалою 100–200 (таблиця переведення 2026 року), розбивка за блоками, розбір кожного завдання.
- **Тренажер.** Завдання по одному з миттєвою перевіркою. При помилці пояснення відкривається автоматично. Варіанти відповідей перемішуються, фільтр за варіантом і блоком, режим «лише ще не розв'язані».
- **Робота над помилками.** Усі завдання з неправильною відповіддю збираються в список. Правильна відповідь прибирає завдання зі списку.
- Прогрес зберігається в `localStorage` браузера. Є експорт та імпорт у JSON для перенесення між пристроями.

Клавіатура: `1`–`4` вибір відповіді, `→` або `Enter` далі, `←` назад.

## Формат тесту

За характеристикою УЦОЯО на 2026 рік ТЗНК містить 27 завдань: завдання 1–4 це мікротексти з 10 пропусками (1 бал за пропуск), завдання 5–27 з вибором однієї відповіді (23 бали). Разом 33 тестові бали за 75 хвилин. Тренувальні варіанти показують кожен пропуск окремим пунктом, тому в застосунку 33 пункти на варіант.

## Дані

Завдання, правильні відповіді та пояснення взято з тренувальних варіантів на [ЗНО-онлайн (Освіта.ua)](https://zno.osvita.ua/master/tznpk/). Файл `data.js` генерує `scrape.py`:

```bash
python3 -m venv .venv
.venv/bin/pip install requests beautifulsoup4 lxml
.venv/bin/python scrape.py            # варіанти 646–650
.venv/bin/python scrape.py 651        # додати ще один варіант
```

Скрипт зберігає картинки в `img/<variant>/` і виносить спільний текст групи завдань (тексти для читання, описи ситуацій) в окреме поле `passage`, щоб показувати його один раз.

## Хостинг

Це один `index.html` плюс `data.js` та папка `img/`. Працює з GitHub Pages або відкритий з диска.
