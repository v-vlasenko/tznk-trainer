# ТЗНК тренажер

Статичний тренажер для підготовки до тесту загальної навчальної компетентності (ТЗНК), обов'язкового блоку ЄВІ для вступу до магістратури.

## Що вміє

- **Симуляція іспиту.** Повний тренувальний варіант: 33 пункти, таймер 75 хвилин, порядок відповідей як в оригіналі. Результат у тестових балах і орієнтовно за шкалою 100–200 (таблиця переведення 2026 року), розбивка за блоками, розбір кожного завдання.
- **Тренажер.** Завдання по одному з миттєвою перевіркою. При помилці пояснення відкривається автоматично. Варіанти відповідей перемішуються, фільтр за варіантом і блоком, режим «лише ще не розв'язані».
- **Робота над помилками.** Усі завдання з неправильною відповіддю збираються в список. Правильна відповідь прибирає завдання зі списку.
- Прогрес зберігається в `localStorage` браузера. Є експорт та імпорт у JSON для перенесення між пристроями.

Клавіатура: `1`–`4` вибір відповіді, `→` або `Enter` далі, `←` назад.

## Формат тесту

За характеристикою УЦОЯО на 2026 рік ТЗНК містить 27 завдань: завдання 1–4 це мікротексти з 10 пропусками (1 бал за пропуск), завдання 5–27 з вибором однієї відповіді (23 бали). Разом 33 тестові бали за 75 хвилин. Тренувальні варіанти показують кожен пропуск окремим пунктом, тому в застосунку 33 пункти на варіант.

## Дані

Вісім варіантів по 33 пункти: п'ять тренувальних, демоваріанти УЦОЯО 2023 і 2024, основна сесія ЄВІ 2024. Завдання, правильні відповіді та пояснення сайту взято з [ЗНО-онлайн (Освіта.ua)](https://zno.osvita.ua/master/tznpk/). Для демоваріанта 2024 додано офіційні обґрунтування УЦОЯО з PDF.

До кожного завдання є власний розбір (`explanations/<variant>.json`, формат у `explanations/SPEC.md`): відповідь, хід розв'язання, чому інші варіанти хибні, як розпізнати тип завдання. Розбір не посилається на літери варіантів, тому працює і при перемішаних відповідях.
Коли розбір є, пояснення сайту не показується; офіційне обґрунтування УЦОЯО лежить згорнутим під розбором разом зі списком варіантів у їхньому оригінальному порядку літер. Перевірка формату розборів: `.venv/bin/python check_reviews.py`.

Дефекти сторінок-джерел (злиті варіанти відповідей, одруки в умові) виправляє `patches.json`, який `build.py` застосовує після скрапінгу. Формули у вигляді MathJax `\(\frac 25\)` перетворюються на звичайний текст `2/5`.

```bash
python3 -m venv .venv
.venv/bin/pip install requests beautifulsoup4 lxml
.venv/bin/python scrape.py            # усі відомі варіанти, потім злиття розборів
.venv/bin/python scrape.py 651        # додати ще один варіант
.venv/bin/python build.py             # лише злити розбори в data.js
```

Скрипт зберігає картинки в `img/<variant>/` і виносить спільний текст групи завдань (тексти для читання, описи ситуацій) в окреме поле `passage`, щоб показувати його один раз.

## Синхронізація прогресу

Без входу прогрес живе в localStorage браузера. Кнопка «Увійти через Google» у шапці вмикає синхронізацію через Firebase (проєкт `tznk-trainer`, Spark-план): документ `users/<uid>` у Firestore з тим самим JSON, що й локально. Локальна копія лишається основною, хмара зливається з нею об'єднанням історій і максимумом лічильників, тому телефон і ноутбук не затирають один одного. Правила доступу в `firestore.rules`: кожен читає й пише лише свій документ, акаунти зі списку `admins` у `firebase-config.js` бачать сторінку «Прогрес усіх».

**Повідомити про проблему** у меню профілю: текст плюс скріншот (файл або Ctrl+V), стискається до JPEG ≤ 850 КБ і лягає в колекцію `feedback` (адміни бачать її в меню «Відгуки»). Щоб кожне повідомлення ще й приходило на пошту: розгорнути `feedback-hook.gs` як Apps Script web app (кроки в шапці файлу) і вписати URL розгортання в `feedbackHook` у `firebase-config.js`.

Резервна копія всіх документів (на Spark-плані автоматичних бекапів немає): `.venv/bin/python backup.py`, файл лягає в `~/tznk-backups/`. Публічний API-ключ обмежений доменами сайту.

Оновити правила після зміни:

```bash
T=$(gcloud auth print-access-token); P=tznk-trainer
RN=$(curl -s -X POST -H "Authorization: Bearer $T" -H "x-goog-user-project: $P" -H "Content-Type: application/json" \
  "https://firebaserules.googleapis.com/v1/projects/$P/rulesets" \
  -d "$(python3 -c 'import json;print(json.dumps({"source":{"files":[{"name":"firestore.rules","content":open("firestore.rules").read()}]}}))')" | python3 -c 'import json,sys;print(json.load(sys.stdin)["name"])')
curl -s -X PATCH -H "Authorization: Bearer $T" -H "x-goog-user-project: $P" -H "Content-Type: application/json" \
  "https://firebaserules.googleapis.com/v1/projects/$P/releases/cloud.firestore" -d "{\"release\":{\"name\":\"projects/$P/releases/cloud.firestore\",\"rulesetName\":\"$RN\"}}"
```
